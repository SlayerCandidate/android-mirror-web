# Android Mirror

A modern browser-inspired Android mirroring landing page, designed to feel like a simplified version of the USB debugging screen-mirroring experience.

## Features
- Dark, polished interface inspired by desktop mirroring tools
- Device preview card with live status styling
- Responsive layout for desktop and mobile
- Mock interaction states for start/stop, screenshot, and recording actions

## Run locally
Open `index.html` directly in a browser, or serve the project with any static file server:

```bash
python3 -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Notes
This is a front-end mockup for a browser-based Android mirror interface. It is intentionally a UI clone/landing page rather than a real ADB or USB debugging implementation.
